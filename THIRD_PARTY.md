# Credits and licenses

OpenVST Manager is an independent implementation. Its installation workflow was inspired by [The Usual Suspects Plugin Manager](https://theusualsuspects.io/downloads/plugin-manager), whose source is in [Gearmulator](https://github.com/dsp56300/gearmulator/tree/main/source/framework/tools/installer). No Gearmulator code or artwork is included.

Runtime components include Electron (MIT, with Chromium and other bundled licenses), React (MIT), Lucide icons (ISC), semver (ISC), and yauzl (MIT). Their licenses remain in the installed dependencies and Electron distribution. Build tools are listed in package.json and pinned by package-lock.json.

The manager's MIT license applies to the manager. Downloaded plugins retain their own licenses and notices; the source repository and exact release are linked from every plugin. VST is a trademark of Steinberg Media Technologies GmbH. Winamp names refer to independently developed projects, not affiliation.

Artwork provenance and the generation prompt are recorded in [assets/ARTWORK.md](assets/ARTWORK.md).
